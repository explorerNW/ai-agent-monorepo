| 选项                            | 用途                                                      |
| :------------------------------ | :-------------------------------------------------------- |
| single-spa root config          | 基座/入口。负责路由分发、子应用注册、全局Layout、统一登录 |
| single-spa application / parcel | 具体的业务子应用（如订单中心、用户管理）                  | ❌ 后续建子应用时再选 |
| in-browser utility module       | 跨应用共享的工具库（如鉴权SDK、UI组件库、API缓存）        | ❌ 需要时再选         |
